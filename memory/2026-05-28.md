  Turbo ControlNet patch reference`.
- Local ControlNet wiring uses `LoadImage -> AIO_Preprocessor` with
  `DepthAnythingV2Preprocessor`, a `PreviewImage` for the depth map,
  `ModelPatchLoader`, and `ZImageFunControlnet` before the sampler model input.
- Official Comfy workflow uses ControlNet strength `1.0`. Alibaba-PAI documents
  a useful scale range around `0.65-1.00`; for local LoRA-heavy/body-contact
  tests, start around `0.65-0.8` and tune upward only if structure is too weak.
